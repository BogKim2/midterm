## 1. 개요

### 1.1 제품 목적

Smart Document Analyzer는 사용자가 텍스트를 직접 입력하거나 로컬 문서 파일을 불러오면, 외부 AI API 호출 없이 로컬 환경에서 문서의 통계, 키워드, 감정, 가독성, 문장 구조를 분석하고 시각화하는 데스크톱 애플리케이션이다.

본 프로젝트는 웹 배포보다 로컬 실행과 데스크톱 사용성을 우선하며, 과제 데모에서 “문서 입력 → 분석 → 시각 결과 확인 → 결과 저장” 흐름을 안정적으로 보여주는 것을 목표로 한다.

### 1.2 배경

기존 Streamlit 기반 웹앱 구조는 빠른 프로토타이핑에는 적합하지만, 데스크톱 애플리케이션처럼 완성도 있는 UI, 파일 기반 워크플로우, 패키징된 실행 파일 제공에는 한계가 있다. PySide6 기반 데스크톱 앱으로 전환하면 다음 장점을 얻을 수 있다.

- 브라우저 없이 앱을 실행할 수 있다.
- 로컬 파일 열기, 저장, 내보내기 경험을 자연스럽게 제공할 수 있다.
- 오프라인 분석 앱이라는 제품 컨셉이 명확해진다.
- 과제 제출 시 실행 파일 또는 로컬 실행 방식으로 시연하기 쉽다.
- UI 레이아웃, 메뉴, 단축키, 진행 상태 표시 등 데스크톱 앱다운 완성도를 확보할 수 있다.

### 1.3 제품 비전

긴 문서를 읽기 전에 “문서의 핵심 구조와 분위기”를 빠르게 파악할 수 있는 로컬 문서 분석 도구를 제공한다.

## 6. 사용자 흐름

### 6.1 기본 분석 흐름

1. 사용자가 앱을 실행한다.
2. 시작 화면에서 “텍스트 붙여넣기” 또는 “파일 열기”를 선택한다.
3. 문서 내용이 입력 패널에 표시된다.
4. 사용자가 “분석하기” 버튼을 클릭한다.
5. 앱이 백그라운드에서 분석을 수행한다.
6. 결과 화면에 다음 항목이 표시된다.
   - 기본 통계 카드
   - 키워드 빈도 차트
   - 감정 분석 카드
   - 워드클라우드
   - 가독성 점수
   - 문장 길이 분포
7. 사용자는 결과를 JSON 또는 이미지로 저장할 수 있다.

### 6.2 오류 흐름

| 상황 | 앱 동작 |
|---|---|
| 텍스트가 비어 있음 | “분석할 텍스트를 입력하거나 파일을 선택하세요.” 메시지 표시 |
| 지원하지 않는 파일 형식 | “현재는 .txt, .md 파일만 지원합니다.” 메시지 표시 |
| 파일 인코딩 오류 | UTF-8 재시도 후 실패 시 안내 메시지 표시 |
| 텍스트가 너무 김 | 경고 표시 후 분석 진행 여부 확인 |
| 분석 중 예외 발생 | 앱 종료 없이 오류 메시지와 재시도 버튼 표시 |

## 7. 화면 요구사항

### 7.1 메인 화면

| 영역 | 구성 요소 |
|---|---|
| 상단 메뉴 | 파일 열기, 저장, 종료, 도움말 |
| 좌측 입력 패널 | 텍스트 입력창, 파일명, 글자 수 표시 |

결과 화면은 탭 구조를 사용한다.

| 탭 | 내용 |
|---|---|
| Overview | 기본 통계, 감정 라벨, 가독성 요약 |
| Keywords | 키워드 표, 키워드 빈도 차트 |
| Visualization | 워드클라우드, 문장 길이 분포 |
| Export | JSON 저장, 이미지 저장, 분석 메타데이터 확인 |

## 9. 데이터 및 개인정보 정책

- 사용자가 입력한 텍스트와 파일은 기본적으로 메모리에서만 처리한다.
- 사용자가 명시적으로 저장하지 않는 한 원본 문서를 앱 내부에 저장하지 않는다.
- 분석 결과 저장 시 사용자가 지정한 위치에만 파일을 생성한다.
- 외부 AI API, 클라우드 서버, 원격 데이터베이스로 문서 내용을 전송하지 않는다.
- 오류 로그에는 원문 텍스트 전체를 저장하지 않는다.

## 10. 제약사항

| 제약 | 설명 |
|---|---|
| 영어 중심 분석 | 감정 분석과 Flesch 가독성은 영어 텍스트에 최적화 |
| 한국어 가독성 | MVP에서는 한국어 가독성 점수를 공식 지표로 제공하지 않음 |
| 파일 형식 | MVP에서는 `.txt`, `.md`만 지원 |
| 대용량 문서 | 10만 자 초과 문서는 처리 시간이 길어질 수 있음 |
| 오프라인 NLP | 고급 요약/추론 기능은 외부 AI API 없이 제공하지 않음 |
