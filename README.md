## 113prigio

`113prigio` (Prigio)는 냉장고 AI 식재료 관리·사진 분석·레시피 추천 풀스택 웹앱입니다. FastAPI + 로컬 PostgreSQL + LM Studio, React + Vite + TypeScript + Tailwind.

See [113prigio/README.md](./113prigio/README.md) and [113prigio/plan_local.md](./113prigio/plan_local.md) for setup and architecture notes.

## 12mct

`12mct`는 LM Studio 연동 식사 칼로리 추적 웹앱 MVP입니다. React + Vite 프론트엔드, FastAPI + TensorFlow 백엔드.

See [12mct/README.md](./12mct/README.md) for local setup.

## 108saju

`108saju` is a React + TypeScript + Vite project for an AI-based saju experience.

- Core flows: landing, saju input, result, analysis
- Extra pages: compatibility, calendar, timeline, login, signup, mypage, premium
- Local AI integration: LM Studio compatible endpoint
- Saju core improvement: solar/lunar conversion and gapja-based pillar calculation

See [108saju/README.md](./108saju/README.md) for local setup and project details.

## 110dungeon

`110dungeon` is a FastAPI + React (Vite) AI text dungeon RPG: Google OAuth, SQLite, and LM Studio (OpenAI-compatible local LLM, e.g. Qwen3).

See [110dungeon/README.md](./110dungeon/README.md) and [110dungeon/plan.md](./110dungeon/plan.md) for setup and architecture notes.
